# Short Scanner

Сканер монет, которые слабеют, пока BTC растёт, плюс шорт на Bybit лимитками с догоном и аварийным стопом.

- `public/index.html` — сканер и торговый интерфейс (ордера подписываются в браузере).
- `server.js` — отдаёт страницу и проксирует запросы `/mainnet|/demo|/testnet/v5/...` на Bybit (без CORS).

## Railway

Переменные окружения:

- `AUTH_USER`, `AUTH_PASS` — логин и пароль для входа на сайт (обязательно).

Регион сервиса — **Europe (Amsterdam)** или Asia: Bybit блокирует запросы с US-IP.

## Локально

```
node server.js   # http://localhost:8080
```

## Автобот 24/7

`bot.js` работает на сервере постоянно: каждые N минут сканирует рынок, и если BTC растёт —
открывает шорты по сигналам «вход» лимитками с догоном (PostOnly), ставит аварийный стоп (+25% от входа, по mark price)
и TP-лимитки 50/50, закрывает позиции, которые держатся дольше лимита. Свои ордера помечает `orderLinkId` `bts-…`.
Монеты, по которым на аккаунте уже есть позиция или ордера (другие боты), не трогает.

Переменные: `BYBIT_API_KEY`, `BYBIT_API_SECRET`, `BYBIT_ENV` (mainnet), `BOT_ENABLED` (true/false — стартовое значение),
`BOT_MAX_POS` (5), `BOT_USD` (50), `BOT_LEV` (3), `BOT_SL_PCT` (25), `BOT_MIN_SCORE` (60), `BOT_MAX_HOLD_H` (24), `BOT_SCAN_MIN` (5).
Настройки, изменённые на странице, сохраняются на volume (`bot-config.json`).
